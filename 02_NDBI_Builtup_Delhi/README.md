# Built-Up Area Mapping Using NDBI – Delhi

## Overview
This project maps built-up areas across Delhi using the Normalized Difference Built-up Index (NDBI).

## Study Area
Delhi, India

## Data
- Landsat 8 OLI imagery
- Delhi administrative boundary

## Methodology
- Landsat bands were clipped to the study area
- NDBI was calculated using SWIR and NIR bands
- Higher NDBI values were interpreted as built-up surfaces
- Map layout was designed for urban interpretation

## Results and Interpretation
High NDBI values are concentrated in dense urban and commercial zones, industrial areas, and major transport corridors.  
Lower or negative values correspond to vegetation, water bodies, and open land.

## Output
- Built-up area map (PDF)

## Skills Demonstrated
- Spectral index analysis
