# Urban Green Cover Assessment Using NDVI – Delhi

## Overview
This project evaluates vegetation distribution and density across Delhi using the Normalized Difference Vegetation Index (NDVI).

## Study Area
Delhi, India

## Data
- Landsat 8 OLI imagery
- Delhi administrative boundary

## Methodology
- Landsat bands were clipped to the Delhi boundary
- NDVI was calculated using raster analysis
- NDVI values were classified to represent vegetation intensity
- Final map layout was prepared for clear interpretation

## Output
- NDVI green cover map (PDF)
- ## Results and Interpretation

The NDVI map highlights clear spatial variation in vegetation cover across Delhi.

Higher NDVI values are observed in:
- Forested areas and biodiversity parks
- River floodplains along the Yamuna
- Large urban green spaces and institutional campuses

Moderate NDVI values correspond to:
- Residential areas with mixed built-up and vegetation
- Urban parks and roadside greenery

Low or negative NDVI values represent:
- Dense built-up areas
- Transportation corridors
- Bare land and water bodies

The results demonstrate the uneven distribution of urban green spaces and help identify areas with limited vegetation cover.
