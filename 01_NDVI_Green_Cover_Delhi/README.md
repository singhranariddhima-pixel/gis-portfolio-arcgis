# Urban Green Cover Assessment Using NDVI – Delhi

## Overview
This project evaluates vegetation distribution and density across Delhi using the Normalized Difference Vegetation Index (NDVI).

## Study Area
Delhi, India

## Data
- Landsat 8 OLI imagery
- Delhi administrative boundary

## Methodology
- Landsat bands were clipped to the Delhi boundary
- NDVI was calculated using raster analysis
- NDVI values were classified to represent vegetation intensity
- Final map layout was prepared for clear interpretation

## Output
- NDVI green cover map (PDF)

## Skills Demonstrated
- Raster analysis
- Spectral indices
- Cartographic layout design
