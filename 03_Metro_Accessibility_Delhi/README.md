# Metro Accessibility Analysis (500–1000 m Buffers) – Delhi

## Overview
This project evaluates urban accessibility to metro stations in Delhi using buffer-based spatial analysis.

## Study Area
Delhi, India

## Data
- Delhi Metro station locations
- Delhi administrative boundary

## Methodology
- Metro stations were mapped as point features
- Multiple buffer zones (500 m and 1000 m) were created
- Accessibility zones were categorized as high, moderate, and low
- Final map layout highlights spatial accessibility patterns

## Results and Interpretation
Areas within 500 m buffers show high accessibility, primarily concentrated in central and well-connected corridors.  
Peripheral zones beyond 1000 m indicate lower metro accessibility, highlighting spatial inequality in transit access.
